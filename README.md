# Portfólio de Quality Assurance (QA)

Este repositório reúne projetos e atividades práticas desenvolvidos durante minha formação no curso **Engenheiro de Qualidade de Software da EBAC**.

O objetivo é apresentar minha evolução na área de Quality Assurance (QA), reunindo projetos relacionados a testes de software, automação, qualidade, desempenho e ferramentas utilizadas no processo de desenvolvimento e validação de aplicações.

## Projetos

### 01. Cypress UI — Testes de interface

Projeto de automação de testes de interface da aplicação Hub de Leitura, utilizando Cypress e dados gerados para apoiar os cenários de teste.

**Tecnologias:** Cypress, JavaScript e Faker.

[Acessar projeto](./01-cypress-ui/)

### 02. Testes de API REST

Projeto de testes de API REST utilizando Cypress para realizar requisições e validar os serviços da aplicação.

**Tecnologias:** Cypress, JavaScript e API REST.

[Acessar projeto](./02-api-testing/)

### 03. Integração contínua com GitHub Actions

Projeto de configuração de integração contínua para automatizar a execução de testes utilizando GitHub Actions.

**Tecnologias:** GitHub Actions, Cypress e JavaScript.

[Acessar projeto](./03-devops-github-actions/)

### 04. Testes com Docker

Projeto de configuração de ambiente com Docker para execução de testes automatizados utilizando Cypress.

**Tecnologias:** Docker, Dockerfile e Cypress.

[Acessar projeto](./04-docker/)

### 05. Cypress avançado com BDD

Projeto de automação de testes utilizando BDD e Gherkin para organizar os cenários de teste de forma clara e estruturada.

**Tecnologias:** Cypress, JavaScript, BDD e Gherkin.

[Acessar projeto](./05-cypress-advanced-bdd/)

### 06. Testes de performance

Projeto de testes de desempenho utilizando Apache JMeter, com cenários de carga e arquivo de massa de dados.

**Tecnologias:** Apache JMeter, JMX e CSV.

[Acessar projeto](./06-performance-testing/)

### 07. Automação de testes mobile

Projeto de automação de testes em aplicativo Android utilizando Appium e WebdriverIO.

**Tecnologias:** Appium, WebdriverIO, JavaScript e Android.

[Acessar projeto](./07-mobile-appium/)

### 08. Testes unitários com Jest

Projeto de implementação de testes unitários em JavaScript, com validações de funções relacionadas ao cadastro de usuários.

**Tecnologias:** JavaScript, Jest e Node.js.

[Acessar projeto](./08-javascript-jest/)

### 09. Inteligência Artificial aplicada ao QA

Projeto de planejamento de testes para a aplicação Hub de Leitura, utilizando inteligência artificial como apoio à análise de requisitos, elaboração de cenários em Gherkin e identificação de riscos.

**Tecnologias:** ChatGPT, QA e Gherkin.

[Acessar projeto](./09-ai-in-qa/)

## Objetivo do portfólio

Reunir e apresentar os conhecimentos desenvolvidos durante minha formação em Qualidade de Software, por meio de atividades práticas envolvendo diferentes tipos de testes, ferramentas e abordagens utilizadas na área de QA.

## Tecnologias e ferramentas

- Cypress
- JavaScript
- Node.js
- Postman
- Git e GitHub
- GitHub Actions
- Docker
- BDD e Gherkin
- Apache JMeter
- Appium
- WebdriverIO
- Jest
- ChatGPT
